# aaj_ki_naari_dashboard
**Aaj Ki Naari: India’s Growth, But at What Cost?**  An interactive dashboard exploring the connection between women’s health, social agency, and India’s development. Using NFHS data, it examines nutrition, anaemia, menstrual health, digital access, financial inclusion, property ownership, family planning, and women’s safety.  
# Aaj Ki Naari: India’s Growth, But at What Cost?

An interactive dashboard exploring women's health, agency, and development in India.

### Key Themes
- Nutrition and anaemia
- Menstrual health
- Digital access
- Financial inclusion
- Property ownership
- Family planning and decision-making
- Women's safety

### Data Sources
NFHS-5 (2019–21) and other sources cited in the dashboard.

### Purpose
To explore the gaps between India's development and women's health, safety, and empowerment through data and interactive visualisation.
